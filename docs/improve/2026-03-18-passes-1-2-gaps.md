- animated-donut-pro — connector line labels — no font-size / font-color setting (uses deprecated donutSettings.labelColor/labelFontSize that are hidden at runtime; actual rendering at L675-676 still reads them but they are not visible in the pane — user cannot change them)

- animated-donut-pro — connector lines — no line style setting (solid/dashed)
- animated-donut-pro — nested inner ring segments — stroke hardcoded to `#FFFFFF` (L788); no setting for inner ring stroke color
- animated-donut-pro — nested inner ring segments — stroke-width hardcoded to `0.5` (L789); no setting for inner ring stroke width

### Shape fill gaps
- animated-donut-pro — nested inner ring — no per-segment color control; colors are auto-derived from parent via `withOpacity`

### Show/hide toggle gaps
- animated-donut-pro — connector lines — has toggle (`connectorLines`) but connector color/width/style are not exposed

### Number formatting gaps
- animated-donut-pro — center value — uses local `ValueSettings` prefix/suffix/decimals, does NOT use shared `NumberFormattingCard` (separate formatNumber call at L874; `formatWithSettings` is only used for labels)
