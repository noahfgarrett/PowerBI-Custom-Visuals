KPI Card Pro

KPI & Cards

Advanced KPI card with count-up animation, trend arrow, sparkline, and glassmorphic styling. Ideal for headline metrics on executive dashboards.

Data Fields

M
Value (Measure)
The main KPI number to display — e.g., total revenue, count of orders, average score
M
Target (Measure) Optional
Comparison value for the trend arrow. The card shows green up-arrow if Value > Target, red down-arrow if below.
G
Trend Axis (Grouping) Optional
Date or sequence field for the sparkline X-axis (e.g., Week, Month, Quarter)
M
Trend Values (Measure) Optional
Values for each point on the sparkline trend line
G
Category Label (Grouping) Optional
Subtitle text displayed above the value. Overridden by custom text in the Format pane.

Example Use Cases

  • Total revenue with target comparison and monthly trend sparkline
  • Headcount KPI with quarter-over-quarter trend
  • Customer satisfaction score with threshold arrow
Tip: You can drop in just a Value measure with nothing else — the card works in its simplest form. Add Trend Axis + Trend Values to enable the sparkline, and Target to enable the trend arrow.
